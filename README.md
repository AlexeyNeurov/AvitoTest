# Avito candidate generation

`solution.py` строит локальный гибридный поиск по объявлениям и создаёт
`answer.csv` для метрики Recall@50. Внешние API и скрытые данные не используются.

## Подход

1. Из корпуса берутся объявления услуг (`item_category_id == 114`). Это следует
   из train: практически все выбранные объявления относятся к этой категории.
2. Строятся разреженные текстовые индексы:
   - словарные униграммы по заголовку, параметрам и началу описания;
   - символьные n-граммы 3–5 по заголовку и параметрам;
   - BM25 по русским стеммам с нормализацией длины документа;
   - отдельные униграммы и биграммы по заголовку доступны для абляций.
3. По train рассчитываются дополнительные сигналы:
   - исторические клики для точного запроса и контекста;
   - клики по близким формулировкам запросов;
   - слабый prior популярности объявления;
   - Complement Naive Bayes для top-3 микрокатегорий нового запроса;
   - распределение микрокатегорий для структурированных поисковых фильтров.
4. Структурированный фильтр запроса отдельно сопоставляется с параметрами
   объявления символьными n-граммами. Небольшой вес `0.08` выбран на holdout:
   он улучшает тип услуги и устойчив к русским окончаниям, не вытесняя основной
   текстовый сигнал.
5. Лексические кандидаты объединяются и переранжируются с учётом этих сигналов.
   Для городского поиска используется точный город и соседние города в радиусе
   100 км. Для региональных location_id города и их веса восстанавливаются по
   выборам train; такие региональные ID отсутствуют у самих объявлений.
6. Перед сохранением код проверяет все ограничения формата соревнования.

На строгой локальной проверке по 1 500 уникальным текстам запросов, полностью
исключённым из исторических query-сигналов, базовая версия получила `0.80844`,
а отдельное сопоставление фильтров — `0.81111` Recall@50. Эта оценка нужна для
выбора параметров и не является официальным результатом.

## Зависимости

Основное решение использует open-source библиотеки `pandas`, `NumPy`, `SciPy`,
`scikit-learn`, `PyArrow` и `PyStemmer`. Экспериментальные скрипты семантического
поиска используют `FastEmbed` и `FAISS`; версии перечислены в `requirements.txt`.

```bash
python -m pip install -r requirements.txt
python solution.py --data-dir . --geo-hierarchy --bm25-weight 0.20 --filter-char-weight 0.08 --title-weight 0 --output answer.csv
```

Для повторения локальной проверки:

```bash
python solution.py --data-dir . --validate --validation-size 2500
```

Полный запуск рассчитан на CPU; желательно иметь около 8 ГБ свободной памяти.
